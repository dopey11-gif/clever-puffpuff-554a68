FICHIERS

- about.html : page À propos
- services.html : page Services
- assets/css/style.css : styles et adaptation mobile
- assets/js/script.js : menu mobile et année automatique
- assets/images/logo.svg : logo vectoriel temporaire réalisé pour le site
- assets/images/reference-mockup.png : maquette de référence fournie

MISE EN LIGNE
Le site est statique : HTML, CSS et JavaScript. PHP et base de données ne sont pas nécessaires.
Téléversez tout le contenu du dossier zk-global-site dans le dossier public_html (ou équivalent) de votre hébergement. La page d'accueil doit rester nommée index.html.
